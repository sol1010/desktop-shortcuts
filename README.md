# Desktop Shortcuts

Windows 바탕화면에 폴더·프로그램 바로가기, 투두, 달력을 띄우는 반투명 위젯 앱입니다. C#과 WPF로 만들었습니다.

## 기능

- **바로가기** — 폴더, 실행 프로그램, 앱의 달력을 여는 버튼을 만들 수 있습니다. 버튼별 이름, 크기, 클릭 방식과 항상 위 설정을 지정할 수 있습니다.
- **위젯 배치** — 아이콘과 위젯의 가장자리를 자석으로 맞출 수 있습니다. 투두를 달력 아래에 붙이면 2px 간격으로 함께 움직이고 크기를 조절할 수 있습니다.
- **날짜별 투두** — 하위 투두를 만들고, 체크하면 취소선이 표시됩니다. 항목을 우클릭해 하위 투두와 완료 상태까지 복제할 수 있습니다.
- **달력과 메모** — 날짜별 메모의 첫 네 글자가 달력에 표시됩니다. 높이를 줄이면 주간 보기로 전환되며, 주간 메모란은 접을 수 있습니다. 달력 우클릭 메뉴의 **크게 보기**는 화면 좌우 중 가까운 절반을 채웁니다.

## 빌드와 실행

Windows 11과 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)가 필요합니다. 저장소를 받은 뒤 프로젝트 폴더에서 빌드합니다.

```powershell
dotnet build -c Release
```

빌드가 끝나면 `bin/Release/net10.0-windows/DesktopShortcuts.exe`를 실행합니다. 알림 영역의 **바탕화면 바로가기** 메뉴에서 버튼을 추가하거나 투두와 달력을 열 수 있습니다. 탐색기의 **새 탭에서 열기**는 Windows 11의 탐색기 탭을 사용합니다.

## 저장과 외형 설정

위젯 위치와 크기, 바로가기, 날짜별 투두와 메모는 Windows 사용자 계정의 `%LOCALAPPDATA%\DesktopShortcuts`에 저장됩니다. 실행 파일 옆 `appearance.json`에서 배경색과 아이콘 색, 글자 크기, 모서리 둥글기를 조정하면 열린 위젯에 반영됩니다.
