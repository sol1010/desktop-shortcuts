# Desktop Shortcuts

Windows 바탕화면에 폴더·프로그램 바로가기, 할 일, 달력을 띄우는 반투명 위젯 앱입니다. C#과 WPF로 만들었습니다.

## 기능

- **바로가기 묶음** — 폴더, 프로그램, 달력을 여는 아이콘을 만들 수 있습니다. 아이콘을 자석으로 붙이면 함께 이동하며, 우클릭 메뉴에서 묶음의 크기, 배경 투명도, 클릭 방식, 항상 위를 설정할 수 있습니다. Ctrl을 누른 채 끌어 순서를 바꾸거나 **묶음에서 분리**를 선택해 아이콘을 떼어 놓을 수 있습니다.
- **날짜별 할 일** — 하위 목록을 접고 펼칠 수 있고, 완료한 항목에는 취소선이 표시됩니다. 항목 옆 손잡이를 끌어 순서를 바꾸거나 다른 날짜 칸에 놓아 이동합니다. 우클릭 메뉴의 **항목 복사**와 **항목 붙여넣기**도 사용할 수 있습니다.
- **달력과 메모** — 주간·월간 보기와 화면 절반을 채우는 **크게 보기**를 지원합니다. 날짜 칸에는 할 일 표시와 메모 미리보기가 표시됩니다. 달력 메모와 할 일 메모는 날짜별로 따로 저장됩니다. 구분선을 끌어 영역의 높이를 조절할 수 있습니다.
- **위젯 배치** — 할 일을 달력 아래에 붙이면 2px 간격으로 함께 이동하고, 달력의 배경 투명도를 따릅니다.
- **Windows 자동 실행** — 바탕화면 바로가기나 알림 영역의 폴더 아이콘을 우클릭해 **Windows 시작 시 자동 실행**을 켜거나 끌 수 있습니다.

## 다운로드

[Windows x64 실행 파일](https://github.com/sol1010/desktop-shortcuts/releases/latest/download/DesktopShortcuts-win-x64.exe)을 다운로드해 실행합니다. 실행에 필요한 .NET 런타임이 포함되어 있습니다.

## 소스에서 빌드

Windows 11에서 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)를 설치한 뒤 프로젝트 폴더에서 빌드합니다.

```powershell
dotnet build -c Release
```

빌드가 끝나면 `bin/Release/net10.0-windows/DesktopShortcuts.exe`를 실행합니다. 알림 영역의 **바탕화면 바로가기** 메뉴에서 버튼을 추가하거나 할 일과 달력을 열 수 있습니다. 탐색기의 **새 탭에서 열기**는 Windows 11의 탐색기 탭을 사용합니다.

## 저장과 외형 설정

위젯의 위치와 크기, 바로가기, 날짜별 할 일과 메모는 Windows 사용자 계정의 `%LOCALAPPDATA%\DesktopShortcuts`에 저장됩니다. 저장소의 [appearance.json](appearance.json)을 실행 파일 옆에 두고, 그 파일에서 배경색과 아이콘 색, 글자 크기, 모서리 둥글기를 조정하면 열린 위젯에 반영됩니다.
